# Acquisition and recovery handoff

This Skill remains audit/local-stage only; acquisition and upload are separate authorized platform actions.

Preserve the chain: exact product/variant authority + source page/date -> immutable original -> SHA-256/dimensions/gallery position/provenance/visual QA -> approved mapping -> actual server media IDs/status/count/order -> before-state and separately approved recovery. Expected values copied into an "actual" report are not readback.

Supplier-facing names can use product/shade without barcodes when requested. Keep exact barcode/ID joins in the workbook/manifest, not color labels. Display naming does not replace identity or dictate marketplace filename rules.

Distinct exact-UPC URLs can return identical bytes because of upstream mapping errors. Preserve both provenance and independent shade checks. Visual rejection supersedes an automated save/count PASS. Swatches need post-save crop/color readback, not just filenames or generated all-PASS reports.

Count and order are independent: server CDN fetch may partly fail; local repairs append and scramble interleaving. Expand full galleries and read order after processing. Distinguish changed source galleries from import defects. Destructive gallery rebuild needs exact targets and action-time authorization; original local files cannot restore old cloud media IDs.

Product-gallery-only approval never proves variant binding. Never invent SKU/UPC to pass the variant auditor. If its schema cannot express an approved gallery profile, use an explicit separately reviewed manifest and state the tool limitation until extended/tested.

Merchant thumbnails are not proof of original image_link; unexposed fields remain UNKNOWN. Local READY does not prove publication, feed propagation or Merchant approval. Alt-only work protects existing Alt and exact media ID/URL/order scope.

Historical download/listing/repair scripts with dates, IDs or approved rows are evidence, not reusable execution tools. Before reuse: parameterize input/output, classify network/write effects, add dry-run/drift/idempotency, remove business fixtures/secrets, and test synthetic failures. Do not run them merely to discover their behavior.
