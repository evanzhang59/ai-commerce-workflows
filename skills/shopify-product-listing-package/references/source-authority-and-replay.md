# Source authority and replay safety

Establish authority per field, not a global assumption that one source always wins. Keep raw units and explicit conversions. Similar titles, 1.6 L vs a weight, different can sizes, or pack vs carton are not exact equivalence. Record conditional/missing identities instead of guessing a join.

Same product name alone is a grouping hint, not a universal SPU identity. Use an approved parent key plus exact variant dimensions (Color, Size or other named options), barcode/ID and source evidence. Supplier-facing templates may omit internal SKU/SPU while internal reconciliation retains stable exact keys.

Preserve supplied long descriptions and feature detail; improve structure without inventing ingredients/benefits. Unknown food/compliance facts remain blank or blocked per approved destination profile. A specific merchant's Draft-only/no-SKU/gallery-only exception never removes other stores' gates.

Executed CSVs are historical records, not retry inputs. Fresh duplicate checks and actual created IDs precede any retry. Source-gallery count, remote processed count and final order are separate; route failed CDN mounts to an exact-original recovery plan.

Creating Draft, making Active, publishing channels, adding Collection members, and accepting theme rendering are distinct actions. Keep separate approvals/readbacks and rollback manifests. Partial assortment reset remains PARTIAL even if each performed narrow write passed.
